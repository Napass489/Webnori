เวอร์ชันแก้ Loading พร้อมไฟล์เพลงจริง

ไฟล์ต้นฉบับ: Webnori-main.zip
เพิ่มไฟล์ MP3 ที่แนบภายหลังแล้ว โดยตั้งชื่อ music.mp3 และวางข้าง index.html
ให้อัปโหลดทั้งสองไฟล์ด้วยกัน ไม่ต้องแก้โค้ดหรือตั้งชื่อเพลงเอง

สาเหตุ Loading:
ยังยืนยันสาเหตุบนเว็บออนไลน์ไม่ได้ เพราะไฟล์ที่แนบมี Loading อัตโนมัติและเวลา 1.5 วินาทีอยู่แล้ว ไม่มีตัวแปร storage ที่ข้าม Loading
ปรับให้ CSS ป้องกันหน้าร้านแวบโหลดก่อนสคริปต์ภายนอก รอวาดจอก่อนเริ่มนับเวลา และแจ้งรูปโหลดไม่สำเร็จพร้อมลองใหม่/เข้าร้าน ปรับ fallback ความสูงหน้าจอ และไม่เริ่ม Loading เมื่อกลับจากประวัติเบราว์เซอร์
ใช้ Splash เดิม ไม่มีการเพิ่มกล่องขาวหรือ Splash ซ้อน

เพลง:
ปุ่มเล็กด้านซ้ายบน ห่างขอบบน 64px และพื้นที่ safe area; มาสคอตเดิมอยู่ขวาล่าง
ใช้ audio เดียว วนซ้ำ เริ่มเสียง 30% ขอเล่นเมื่อแตะครั้งแรกหรือกดเปิดเพลง
หยุด/เล่นต่อจากตำแหน่งเดิม เก็บการเลือกหยุดแยกจากข้อมูลร้าน เปลี่ยนแท็บ/เปิดป๊อปอัพไม่สร้าง audio ใหม่
แสดงเล่นเมื่อเล่นจริงเท่านั้น ถ้าไฟล์เพลงผิดมีข้อความแจ้งและร้านยังทำงานได้
Safari/iOS อาจควบคุมระดับเสียงผ่านปุ่มเครื่องแทนค่าในโค้ด ต้องทดสอบบนเครื่องจริง

ตรวจแล้วจริง:
- node --check ผ่านทุก inline JavaScript ในเวอร์ชันส่งมอบล่าสุด
- โค้ดและข้อมูลเดิมของหน้าร้าน รีวิว คะแนน แอดมิน มาสคอต และ localStorage เดิม เหมือนต้นฉบับแบบ byte-for-byte
- ไม่มีการแก้ฐานข้อมูล
ยังไม่ทดสอบจริง: ภาพบนหน้าจอ CSS ทุกขนาด, เบราว์เซอร์ Safari/Android/PC, เสียงจริง, เว็บออนไลน์, ส่งรีวิว/แอดมินแบบโต้ตอบ
เครื่องทดสอบไม่มี browser executable จึงไม่สามารถทดสอบด้วยเบราว์เซอร์ได้

ทดสอบบน iPad หลังอัปโหลด:
1. เปิดลิงก์ Safari และรีเฟรช ต้องเห็น Splash เดิมอย่างน้อย 1.5 วินาทีก่อน Fade
2. ตรวจโลโก้ มาสคอต ข้อความ แถบโหลด และไม่มีกรอบขาว
3. หากรูปไม่มา ต้องเห็นลองใหม่และเข้าร้าน กดลองใหม่เมื่ออินเทอร์เน็ตกลับมา
4. แตะหน้าเว็บ เพลงควรเริ่ม หากยังไม่เล่น กดเปิดเพลง
5. เปิดป๊อปอัพและเปลี่ยนแท็บ เพลงต้องต่อเนื่อง Splash ไม่ซ้ำ
6. กดหยุด เปลี่ยนแท็บ แล้วรีเฟรชและแตะ เพลงต้องไม่เปิดเอง; กดเปิดเพื่อเล่นต่อ
7. ทดสอบไฟล์เพลงผิดชื่อ ต้องแสดงข้อผิดพลาดและยังใช้หน้าร้านได้
8. ตรวจมุมซ้ายบนในแนวตั้ง/นอนว่าไม่ทับปุ่มสำคัญ
9. ตรวจรีวิว คะแนน แอดมิน มาสคอต และกล่องข้อความด้วยตนเอง
อย่าติ๊กผ่านข้อที่ยังไม่ได้ลองจริง

นำขึ้นออนไลน์:
ยังไม่ทราบผู้ให้บริการเว็บของคุณ จึงให้ได้เฉพาะวิธีทั่วไป
สำรองเว็บเดิมก่อน แตก ZIP นี้ แล้วอัปโหลด index.html และ music.mp3 ไปแทนไฟล์ของเว็บเดิมที่โฮสต์เดิม โดยให้ index.html อยู่รากของเว็บ ไม่ซ้อนโฟลเดอร์
ใช้โดเมนเดิมเพื่อคงข้อมูล localStorage ของเว็บเดิม; เปลี่ยนโดเมนอาจไม่เห็นข้อมูลเดิมแม้ไม่มีการลบข้อมูล
รอเผยแพร่สำเร็จแล้วเปิดลิงก์เดิมและรีเฟรช หากยังเห็นเวอร์ชันเดิม ลองแท็บส่วนตัวเพื่อตรวจ cache; อย่าล้างข้อมูลเว็บไซต์ เพราะเว็บนี้เก็บข้อมูลร้าน/รีวิวใน localStorage
แจ้งชื่อโฮสต์หรือส่งภาพหน้าจอเพื่อรับขั้นตอนกดบน iPad ที่ตรงระบบ
